# RoyaleBot AI 2.1

Учебный Android-симулятор с простым табличным Q-learning агентом.

## Сборка
Проект собирается через GitHub Actions. После загрузки файлов откройте вкладку **Actions**, выберите workflow **Build RoyaleBot AI APK** и нажмите **Run workflow**. Готовый APK будет в Artifacts завершённого запуска.

## Важно
Это экспериментальная учебная среда со случайными состояниями и упрощёнными наградами. Она не воспроизводит настоящую Clash Royale, не анализирует видео/реплеи и не управляет игрой. Условные победы и награды относятся только к симуляции.
